Phasmophobia Incense Timer
Phasmophobia Incense Timer is a simple desktop utility for fans of the co‑operative horror game Phasmophobia. It helps you keep track of the short time window during which a smudge stick (incense) calms a ghost. The project is implemented as a WPF application targeting .NET 8.0 for Windows and builds into a lightweight Windows executable.

Why use this?
In the game, incense calms a ghost for only a limited period. If you light incense to stop a hunt, you need to know exactly when its effect wears off. This tool shows a countdown so that you and your team can plan accordingly rather than relying on guesswork.

Features
Two display modes: A traditional Timer layout and an analogue Clock layout to suit different play styles.
Settings menu: Change the length of the countdown and other preferences through an easy‑to‑use settings screen
Simple and lightweight: Built with WPF and compiled as a Windows executable

Download & running
The easiest way to get started is to download a pre‑built binary.
Go to the releases page of this repository and download the latest version of the timer (look for a ZIP or EXE).
Make sure the .NET 8 Desktop Runtime is installed on your Windows machine. You can download it from the official .NET 8 download page (select “.NET Desktop Runtime”)
Extract the archive if necessary and run IncenseTimer.exe. No installation is required; the timer runs as a standalone executable.
If you prefer to build from source, clone the repository and open Incense Timer WPF.sln in Visual Studio. Restore packages and build the project as usual.
